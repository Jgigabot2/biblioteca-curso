# Biblioteca del Curso

Catálogo de libros con préstamos, construido por tres equipos que trabajan en ramas separadas.

| Equipo | Rama | Carpeta | Responsabilidad |
|---|---|---|---|
| Frontend | `frontend` | `frontend/` | La página: catálogo, buscador y préstamos |
| Backend | `backend` | `backend/` | La API descrita en `contrato.md` |
| Testing | `testing` | `tests/`, `.github/` | Pruebas automáticas y revisión de los Pull Requests |

## Ramas

- `main`: versión publicada. Solo recibe cambios desde `develop` al hacer un release.
- `develop`: integración. Los equipos entran aquí por Pull Request.
- `frontend`, `backend`, `testing`: rama de cada equipo.
- `fe/…`, `be/…`, `qa/…`: tareas cortas de cada integrante, que entran a la rama de su equipo.

## Cómo ejecutar

Requisito: Node.js 18 o superior. No hace falta `npm install`: el proyecto no tiene dependencias.

```bash
npm start      # abre http://localhost:3000
npm test       # corre las pruebas
```
